Cheat sheet

Five values, five behaviours

Every offset (top, right, bottom, left) only works when an element is positioned - meaning its position is not static.

static default

Normal flow. Elements stack in order and offsets are simply ignored.

position: static;
relative

Shifts from its own normal spot, but keeps the space it occupied.

position: relative;
absolute

Leaves the flow and anchors to the nearest positioned ancestor.

position: absolute;
fixed

Pins to the viewport and stays put while the page scrolls.

position: fixed;
sticky

Scrolls normally, then sticks once it crosses its offset limit.

position: sticky;

It ignores scrolling

The real navbar at the top of this page is fixed. So is the floating arrow button in the bottom-right corner - it never leaves the viewport while you scroll. 

.topbar {
  position: fixed;
  top: 0;
  left: 0;

}

Demo 04

Sticky - scroll, then stop

position: sticky

This panel scrolls on its own. The heading above will follow you until it reaches the top of the panel, then stay there.

Keep scrolling inside the panel to see the heading stick and the content slide underneath it.

Sticky is the least surprising of the positioned values: it still takes up space in normal flow.

Sticks at top: 0

The offset tells the browser the exact point where the element should stop scrolling. Here it is the very top of the panel.

A common real-world use is a section header inside a long list, or a table header that stays visible.

Releases at the end

A sticky element only sticks inside its parent. When the parent scrolls away, the element goes with it.

That is the difference between sticky and fixed: fixed is tied to the viewport, sticky is tied to its container.

Try it

Scroll the card on the left. Each heading sticks to the top of the panel until its own section is finished. 

.sticky-title {
  position: sticky;
  top: 0;
}

The parent must be taller than the sticky element, and it must not have overflow: hidden.

Z-index - who sits on top?

z-index: 2

Overlap is controlled by z-index

The three cards overlap on purpose. Higher z-index wins, but the property only applies to positioned elements (or flex and grid children). 

.s1 { position: absolute; z-index: 1; }
.s3 { position: absolute; z-index: 3; }

Without positioning, z-index does nothing at all.
